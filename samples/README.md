# Sample Excel files

Made-up invoices in the shapes real accounting exports take, with problems planted in them
(duplicates, a changed bank account, a split bill, a look-alike vendor and more). Use them to
try the app, or as test files. None of this is real data.

| File | Looks like | What it exercises |
|---|---|---|
| `quickbooks-unpaid-bills.xlsx` | QuickBooks "Unpaid Bills Detail" report | Title rows above the header, US dates, `Num` and `Name` columns, a TOTAL row, no bank details |
| `european-supplier-ledger.xlsx` | A European supplier ledger | Dates typed as text day-first (31/03/2026), amounts typed as `1.234,56`, net/VAT/gross columns, IBANs |
| `ap-register-2026.xlsx` | A hand-kept accounts-payable register | One sheet per quarter plus a notes sheet, `$1,234.50` and plain numbers mixed, blank lines, a row with amount `TBC` |
| `invoice-template.xlsx` | A blank template | The columns the app needs, with one example row |

In the web app, the **Upload invoices** page has a **Try it** button for each one, so you don't
need to download them first. For the AP register, import the sheets one after another
(Q1, then Q2, ...); the history builds up and the later quarters get flagged.

These files are generated by `src/invoice_detector/samples.py`. After changing that file, run
`python scripts/make_samples.py` from the repository root; a test checks the copies here match.
